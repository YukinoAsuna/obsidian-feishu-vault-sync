# Feishu Vault Sync

将当前 Obsidian Vault 的笔记、附件和目录结构镜像到飞书云盘，并可选择将飞书端原始文件的变化同步回本地。无需手工创建飞书应用或填写任何凭证：点击连接、使用飞书扫码即可。

## 功能

- 默认单向同步：Obsidian → 飞书云盘。
- 使用飞书官方 Device Authorization Grant 扫码流程，一键创建专用同步应用并申请所需权限。
- 自动创建 `Obsidian Vault - <仓库名>` 云盘目录，并共享给扫码用户。
- 可选双向同步：飞书端被替换或修改的原始文件 → Obsidian。
- 保持 Vault 相对目录结构以及 `.md`、图片、PDF 等原始文件格式。
- 支持 Obsidian 左侧丝带按钮、命令面板手动同步、启动同步和按分钟定时同步。
- 设置页提供文件同步状态面板，分别显示失败、待同步、已同步和已取消文件；已同步列表默认折叠。
- 点击左侧云朵按钮或底部状态栏可直接打开同步管理面板；可按路径搜索并单选、多选文件立即上传，也可从命令面板仅同步当前文件。
- 可取消指定文件的同步并删除飞书副本；本地文件保留，定时同步会持续跳过，重新选中上传即可恢复。
- 在 Markdown 编辑器按 `Ctrl+S`（macOS 为 `Cmd+S`）后立即同步当前文件；可在管理面板中关闭。
- 可启用或关闭自动定时同步，并设置 1–10080 分钟的同步间隔。
- 使用 SHA-256 与飞书文件 Token/修改时间检测变化。
- 两端同时修改时，把飞书版本保存为 `*.conflict-feishu-时间戳.*`，再以本地版本同步到飞书。
- 删除传播默认关闭；开启后，本地删除的文件可删除飞书副本，飞书删除的文件会进入本地 `.trash`。

## 为什么不把 Markdown 转成飞书在线文档

飞书在线文档使用块结构，不能无损表示 Obsidian 的 YAML frontmatter、Wiki 双链、块引用、嵌入、插件语法和任意附件路径。插件因此把 `.md` 作为原始文件上传。这样可以完整还原 Vault，但不能直接用飞书在线文档编辑器编辑这些 Markdown 文件。

双向写回适用于飞书云盘中原始文件被上传新版本、替换或通过飞书桌面文件能力修改的情况。目标目录中人工创建的飞书在线文档、表格和多维表格会被跳过。

## 连接飞书

1. 打开 Obsidian 设置 → 第三方插件 → Feishu Vault Sync。
2. 点击“扫码连接飞书”。
3. 使用飞书扫描插件显示的二维码，在手机上确认创建应用和云盘权限。
4. 插件自动保存飞书返回的应用凭证、创建专用同步目录并立即执行首次同步。

整个过程不需要手填 App ID、App Secret 或文件夹 Token。重新授权时再次扫码即可；断开连接只清除本地凭证，不会删除飞书中的文件。

飞书不支持一次性递归上传文件夹；插件会逐级创建文件夹并逐个上传文件。20 MB 以内使用普通上传，更大的文件自动使用 4 MB 分片上传；上传接口频率上限为 5 QPS，因此插件串行并限速上传。

## 安装与构建

```powershell
npm install
npm run build
```

把以下文件复制到 Vault 的 `.obsidian/plugins/feishu-vault-sync/`：

- `main.js`
- `manifest.json`
- `styles.css`

然后在 Obsidian 桌面版的“第三方插件”设置中启用 **Feishu Vault Sync**。扫码注册依赖飞书官方 Node SDK，因此当前版本仅支持桌面端。

## 默认设置

- 同步方向：本地 → 飞书。
- Ctrl+S 同步当前文件：开启。
- 自动定时同步：开启。
- 间隔：30 分钟。
- 启动同步：开启。
- 删除传播：关闭。
- 排除：`.obsidian/**`、`.trash/**`、`.git/**`、`node_modules/**`。

## 安全与限制

- 扫码后飞书返回的 App ID、App Secret 和同步目录 Token 会自动保存在本机 Vault 的 `.obsidian/plugins/feishu-vault-sync/data.json`。不要提交、同步或分享该文件。
- 大文件使用飞书分片上传，但仍受飞书租户容量、单文件大小与 API 配额限制；失败时会记录错误并继续同步其他文件。
- 飞书云盘目录深度最多 15 层、单层节点和总节点数也受飞书限制。
- 远端同名文件首次同步时，本地版本优先。建议使用专用空文件夹作为同步根目录。
- 插件不会同步空目录之外的隐藏 Obsidian 配置；Obsidian Vault API 可见的笔记和附件会参与同步。

## 手动安装后的调试

打开 Obsidian 开发者工具查看以 `Feishu Vault Sync` 开头的日志。同步结果也会显示在状态栏和通知中。
